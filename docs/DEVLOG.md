## 2026-10-09 · 阶段 2：滚轮转动动画

**做了什么**

- `src/game/reelMotion.ts`：单列运动。加速 260ms → 匀速（0.022 符号/ms）→ ease-out 减速并多冲 0.28 格 → 170ms 回弹到位。减速开始时速度与匀速一致，不会顿一下。
- `src/game/reelTape.ts`：滚动经过的就是真实卷轴条带；落点在画面外上方换成服务器停点，画面上已有的符号不会突变。
- `src/game/spinController.ts`：五列同时起转；结果到达后从左到右逐列减速（最早 500ms，间隔 400ms）；急停；请求失败也能安全停下。用 `tick(now)` 驱动，测试里可以模拟时间。
- `src/useReels.ts` + `src/ReelBoard.tsx`：`requestAnimationFrame` 每帧直接写 DOM，转动时 React 不重渲染；预加载全部符号图片。
- `App.tsx` 重写：点击立即转、结果并行请求、按钮在转动中变为"停止"、空格键、赢分从 0 滚动计数、中奖框改为盖在滚轮上的独立图层。
- 服务端返回 `stops`（各列停点）。
- 去掉旧的"中奖图案淡出成空框"效果（那是模仿视频，会把中奖符号藏起来），阶段 4 重新设计中奖表现。

**怎么验证的**

- `npm test`：23/23 通过；`npm run build` 通过。
- 浏览器 1280×720 实测：点击后 36ms 起转；五列在 1.07 / 1.48 / 1.80 / 2.23 / 2.65s 依次停下，2.83s 全部停稳。
- 逐帧读取 DOM：格子位置每帧向下增加约 30%，方向向下。
- 正常停止和急停后，画面上 5×4 符号都与服务器返回的 `grid` 完全一致。
- 急停：总时长 1.4s（正常 2.8s）。
- 中奖例子：9 四连 2×1×2×1 = 4 路 → 400，6 个格子高亮。

**遗留 / 注意**

- 部分符号图片边缘带邻近图案的残边（素材问题，阶段 3 处理）。
- 界面仍叠在参考截图上（阶段 3）。

## 2026-10-09 · 阶段 0 + 阶段 1：项目整理、数学引擎

**做了什么**

- 建立 Git 仓库。第一个提交是整理前的原样快照，方便以后对比或回退。
- 把视频拆帧、截图、`q-test*.png`、旧版 `slot-game.html`、`reference-spin.mp4`、未使用的 `public/symbols/` 移到 `reference/`（被 `.gitignore` 忽略，文件都还在本机）。
- 依赖从 `latest` 改为锁定版本；新增 `@types/node`。
- 新建 `src/engine/`：
  - `symbols.ts` 符号、赔率表、投注规则
  - `reels.ts` 卷轴条带（固定种子洗牌生成）
  - `evaluate.ts` 1024 ways + Scatter 计算
  - `spin.ts` 一次旋转：随机停点 → 盘面 → 计算赢分 → 封顶
  - `rtp.ts` 精确理论 RTP
  - `engine.test.ts` 13 个单元测试
- 新建 `scripts/rtp-report.ts`（`npm run rtp`）。
- `server.mjs` 重写：结果全部来自引擎，用 `crypto.randomInt` 取随机停点；不再"先随机再强行改成三连"。
- `App.tsx` 适配新接口：投注档位、只读 RTP、最大赢分上限设置。
- 端口可通过 `API_PORT` / `WEB_PORT` 配置。

**怎么验证的**

- `npm test`：13/13 通过。
- `npm run rtp`：精确 RTP 96.68%；200 万次模拟 96.59%，中奖率约 36%。
- `npm run build`：通过（包含引擎和测试文件的类型检查）。
- 浏览器实测（另开 8797/4183 端口，没有动正在运行的旧服务）：连续旋转 8 次，余额变化正确；其中一次同时中 "J 5 连 × 1 路 = 400" 和 "9 3 连 × 2 路 = 80"，金额与赔率表手算一致，9 个中奖格全部高亮。
- 测试管理接口：非法值返回 400，合法值保存成功。

**遗留 / 注意**

- 前端动画还是旧实现（阶段 2 处理）。
- 中奖数字仍有旧的"先显示一半"逻辑（阶段 2 处理）。
- 界面仍叠在参考截图上，截图里的余额 542.33、投注 80 是假的（阶段 3 处理）。
- 你电脑上 4173/8787 端口有之前启动的旧 dev server 和旧 API（旧代码），需要重启 `npm run api` 才能用上新引擎。
