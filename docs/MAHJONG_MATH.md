# 麻将连连胡数学调校（STEP-26）

## 正式配置

- 数学版本：`mahjong-math-1.0.0`
- 轴带版本：`mahjong-strips-1.0.0`
- 五条轴带各 100 格，均固定由版本内的常量种子展开；每条含 2 张“胡”，第 2～4 轴各含 5 张金色普通牌。旋转和连锁补牌不会取随机数。
- 高分牌 `FA`、`ZHONG`、`BAI`、`WAN8` 的 3/4/5 列单路赔付为 `37/100`、`111/100`、`444/100` 倍投注。
- 低分牌 `DOT1` 的 3/4/5 列单路赔付为 `28/100`、`84/100`、`336/100` 倍投注；其余低分牌作为连锁填充牌，不单独支付。
- 所有数值在 `MahjongMathConfig` 中以分子/分母存储；正式投注 `100` 虚拟积分使每个 ways 支付为整数。每个付费回合（含全部免费局）继续受 `1,708×` 封顶。

## 调校过程

先以固定线性同余伪随机源和 100 万独立付费回合估计轴带密度与赔付量级：全牌均支付会使中奖率过高；因此保留 4 个高分牌加 1 个低分牌的支付入口，并使用 2% 的“胡”密度把免费局贡献维持在 RTP 的约 14%。初轮正式候选得到 96.6109%，其 95% 区间未覆盖目标，故仅将 `DOT1` 三档由 26/78/312 调至 28/84/336（分母均为 100），随后重新完成正式千万次样本。

## 正式模拟结果

命令：`npm run rtp:mahjong`。固定种子 `0x26102026`，10,000,000 个独立付费回合；每个样本都完整执行其触发的免费旋转直到结束或封顶。95% 区间按 `mean ± 1.96 × s / sqrt(N)` 计算，并同时报告 20 个交错批次的均值范围。

| 指标 | 实测 |
| --- | ---: |
| RTP | 96.9185% |
| 95% 置信区间 | [96.6133%, 97.2237%] |
| 付费局贡献 | 82.8472% |
| 免费局贡献 | 14.0713% |
| 中奖频率 | 20.9548% |
| 免费触发频率 | 0.7783% |
| 每付费回合标准差 | 4.9240× 投注 |
| 第 99 百分位 | 18.13× 投注 |
| 模拟最高赢分 | 1,134.06× 投注 |
| 封顶频率 | 0.0000%（0 / 10,000,000） |
| 20 批均值范围 | 0.912358× ～ 1.035132× |

RTP 距目标 96.95% 为 -0.0315 个百分点，处于 ±0.10 个百分点验收范围，且 95% 区间包含 96.95%。

## 波动性结论

设计冻结的“中等波动”标准为：中奖频率 20%～45%、标准差 3.0～12.0×、第 99 百分位 10～100×、封顶频率不高于每百万付费回合 2 次。上述实测值全部落在范围内；因此本配置属于中等波动。模拟最高值低于 1,708×，并由引擎封顶与单元测试再次保证不会超过上限。
