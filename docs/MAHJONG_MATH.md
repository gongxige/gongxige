# 麻将连连胡数学调校（STEP-26，第 2 次尝试）

## 正式配置

- 数学版本：`mahjong-math-1.1.0`
- 轴带版本：`mahjong-strips-1.1.0`
- 五条轴带各含 100 格；每轴 2 张“胡”，第 2～4 轴各有 5 张金色普通牌。旋转及连锁补牌均不再取随机数。
- 九种普通付费牌都在正式表中有 3/4/5 列赔付，绝无“填充牌”例外。`FA`、`ZHONG`、`BAI`、`WAN8` 为 `705/10000`、`2115/10000`、`8460/10000` 倍；`DOT1` 为 `5/100`、`15/100`、`60/100` 倍；`DOT2`、`DOT3`、`BAM1`、`BAM2` 均为 `1/10000`、`3/10000`、`12/10000` 倍。
- 正式下注档位为 10,000 虚拟积分，因此上述全部有理数赔付在任一 ways 计数下均为整数。每个付费回合（含其全部免费局）仍共用 `1708×` 封顶。

## 调校过程

第 1 次尝试遗漏四种低分牌的支付入口，审计否决。此次先补齐九种牌的完整 3/4/5 列支付，并新增逐牌测试，构造每一种牌的 3/4/5 连及金色命中盘面，验证均能支付、金色牌均会转为百搭。

补全支付入口后，原来的高分倍率使连锁 RTP 过高；依次以 `0.0700`、`0.0710`、`0.0706` 的高分三列首档倍率试算，最后固定为 `0.0705`（后两档保持 3 倍、12 倍关系）。每次都使用固定种子 `0x26102026`，并结算触发的全部免费旋转。

## 正式模拟结果

命令：`npm run rtp:mahjong`。固定种子 `0x26102026`，10,000,000 个独立付费回合；95% 区间按 `mean ± 1.96 × s / sqrt(N)` 计算，并报告 20 个交错批次均值范围。

| 指标 | 实测 |
| --- | ---: |
| RTP | 96.8959% |
| 95% 置信区间 | [96.5784%, 97.2134%] |
| 付费局贡献 | 70.6660% |
| 免费局贡献 | 26.2300% |
| 中奖频率 `P(X > 0)` | 56.2861% |
| 免费触发频率 | 1.5358% |
| 每付费回合标准差 | 5.1221× 投注 |
| 第 99 百分位 | 19.82× 投注 |
| 模拟最高赢分 | 641.80× 投注 |
| 封顶频率 | 0.0000%（0 / 10,000,000） |
| 20 批均值范围 | 0.861146× ～ 1.084691× |

RTP 距离目标 96.95% 为 -0.0541 个百分点，位于 `96.95% ± 0.10%`，且 95% 置信区间包含 96.95%。模拟最高值低于 1,708×；引擎封顶和单元测试同时保证任何单次付费回合不会超过该上限。

## 波动性结论

STEP-23 定义的中等波动口径为：中奖频率 20%～45%、标准差 3.0～12.0×、第 99 百分位 10～100×、封顶频率每百万付费回合不超过 2 次。本配置的标准差、P99 和封顶频率均达标，但 `P(X > 0)` 为 56.2861%，超过中奖频率上限。因此本次配置尚不能诚实标记为“中等波动验收通过”；后续调校需要在不把任一普通付费牌变回非支付牌的前提下降低中奖频率。
