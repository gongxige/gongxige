# 麻将连连胡数学调校（STEP-26，第 3 次尝试）

## 正式配置

- 数学版本：`mahjong-math-1.2.0`
- 轴带版本：`mahjong-strips-1.2.0`
- 五条轴带各含 100 格、每轴 2 张“胡”；第 2～4 轴各有 5 张金色普通牌。旋转和连锁补牌均只按固定轴带取牌。
- 九种普通付费牌全部保留 3/4/5 列赔付入口，没有填充牌例外。`FA`、`ZHONG`、`BAI`、`WAN8` 为 `1097/10000`、`3292/10000`、`13165/10000` 倍；`DOT1` 为 `778/10000`、`2332/10000`、`9339/10000` 倍；`DOT2`、`DOT3`、`BAM1`、`BAM2` 均为 `2/10000`、`5/10000`、`18/10000` 倍。
- 正式模拟投注为 10,000 虚拟积分，所有正式结算为整数；一次付费回合及其全部免费局仍共用 `1708×` 封顶。

## 调校过程

第 2 次尝试已补齐九种牌的支付入口，但随机散布的普通牌使中奖频率达到 56.2861%，超出中等波动 45% 上限。

本次将每条轴带的九种普通牌改为两格一组、且每轴使用不同固定洗牌顺序的连续组。每种牌仍在每条轴带出现，仍有完整 3/4/5 列赔付；但前三轴可同时形成同一普通牌的窗口明显减少。轴带改动后，1,000,000 次预跑的中奖频率为 25.4238%，因此保留该轴带结构。随后按完整付费回合实测 RTP 调整赔付：第一次 10,000,000 次长样本为 95.1945%，据此将主要赔付提高约 1.844%；最终长样本如下。

## 正式模拟结果

命令：`npm run rtp:mahjong 10000000`。固定种子 `0x26102026`，统计 10,000,000 个独立付费回合及其全部免费局；95% 区间为 `mean ± 1.96 × s / sqrt(N)`，并分为 20 个交错批次复核。

| 指标 | 实测 |
| --- | ---: |
| RTP | 96.9489% |
| 95% 置信区间 | [96.4493%, 97.4486%] |
| 付费局贡献 | 80.8089% |
| 免费局贡献 | 16.1400% |
| 中奖频率 `P(X > 0)` | 25.3736% |
| 免费触发频率 | 0.9012% |
| 每付费回合标准差 | 8.0608× 投注 |
| 第 99 百分位 | 21.07× 投注 |
| 模拟最高赢分 | 1404.71× 投注 |
| 封顶频率 | 0.0000%（0 / 10,000,000） |
| 20 批均值范围 | 0.868741× ～ 1.066853× |

RTP 与 96.95% 的差为 -0.0011 个百分点，处在 `96.95% ± 0.10%` 内，且 95% 置信区间包含目标值。模拟最高值低于 1,708×；引擎封顶与单元测试共同保证单个付费回合不会超过此上限。
