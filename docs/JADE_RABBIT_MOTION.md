# 玉兔送财动画参数（按用户提供的参考视频测量）

> 来源：用户 2026-10-12 提供的参考游戏试玩录像（608×848，30 帧/秒，3 分 35 秒）。录像只临时放在 `video-upload` 分支供分析，不进主分支；本文件只记录测量出来的时间和运动参数，不使用录像里的任何图像、文字或标志。
>
> 测量方法：用 ffmpeg 逐帧取出三列卷轴区域的灰度图，相邻两帧做纵向错位比对，找出每帧移动的像素数。中间列 4 个相同符号叠在一起时，测得格子间距 142 像素，用来把像素换算成「格」。量了两次独立的转动，结果一致。

## 一、卷轴转动（阶段 15 / STEP-52）

| 项目 | 测量值 | 我们采用 |
|---|---|---|
| 转动方向 | 符号从上往下走 | 同 |
| 起转 | 先向上抬约 20 像素（约 0.15 格），用时约 0.07 秒，再往下走 | 抬 0.15 格，0.07 秒 |
| 加速 | 约 0.1 秒加到全速 | 0.1 秒 |
| 全速 | 每帧 82 像素，约每秒 17 格；符号清晰，没有拖影 | 每秒 17 格，不加模糊 |
| 三列起转时间 | 左 0、中 +0.05～0.07 秒、右 +0.15～0.17 秒 | 0、0.06、0.15 秒 |
| 减速 | 约 0.4 秒内从全速匀减到全速的一半左右，走过约 5 格 | 0.4 秒，终速为全速的 45% |
| 回弹 | 减速结束时多走约 0.07 格，再用约 0.13 秒退回停点 | 多走 0.08 格，0.13 秒退回 |
| 三列停下时间（从按下旋转算） | 左约 0.9 秒、中约 1.15 秒、右约 1.5 秒 | 0.9、1.15、1.45 秒 |
| 起转蓝光 | 每列开始转时，列框亮起一圈青蓝色光，约 0.3 秒淡掉 | 同 |
