# 第三款游戏需求：玉兔送财（Jade Rabbit，阶段 11）

> 用户提供了一段参考游戏的录屏和 7 张符号图（在 `reference/jade-rabbit/`，不进 Git）。参考游戏是 PG 的《金钱兔 Fortune Rabbit》。
> 我们只借鉴**玩法、数学结构和画面节奏**，做一款**自己的**游戏：
> - 名字用「玉兔送财」（英文 Jade Rabbit），**不用**"金钱兔""Fortune Rabbit"、PG 的名字和标志。
> - `reference/jade-rabbit/symbols/` 里的图是参考游戏的美术（福袋上还印着 PG 标志），**只能用来看风格，不能放进游戏、不能描摹**。符号、吉祥物兔子、背景、按钮全部用 CSS / 内联 SVG / Canvas 自己画，兔子要是自己设计的形象。
> - 运行时代码不能引用 `reference/` 里的任何文件（CLAUDE.md 已有这条）。
> - 和平台一样，只用虚拟积分。

## 一、从录屏里看到的规则（游戏内"游戏规则""赔付表"页面）

| 项目 | 参考游戏的规则 |
|---|---|
| 盘面 | 3 个卷轴；第 1、3 卷轴 3 行，第 2 卷轴 4 行 |
| 中奖线 | 10 条固定中奖线，从最左到最右（3 个卷轴都要连上）；每条线只付最高的那个奖；不同线的奖相加 |
| 线奖 | 赔付表数值 × 每线投注（= 总投注 ÷ 10） |
| 赔付表（3 连） | 百搭 200、元宝 100、福袋 50、红包 10；铜钱、鞭炮、胡萝卜的数值录屏里被截掉了，按低分符号自己定 |
| 百搭 | 替代除奖金符号以外的所有符号；本身 3 连也赔 200 |
| 奖金符号 | 任何一次旋转都可能出现；每个奖金符号带一个数值，范围是总投注的 0.5 倍到 500 倍；盘面任意位置出现 **5 个或以上**奖金符号，付所有奖金符号的数值之和 |
| 玉兔模式（参考里叫"金钱兔模式"） | 任何一次旋转都可能**随机**触发，给 8 次"财富旋转"；这 8 次里卷轴上**只会出现奖金符号**（其余位置是空白格） |
| 最高赢分 | 总投注的 5,000 倍；主游戏或玉兔模式的总赢分达到 5,000 倍时，这一轮立即结束 |
| RTP | 录屏里没有写。按 **96.75%** 设计（参考游戏公开的数值），用户可以改 |
| 波动性 | 录屏里没有写。按**中等**设计 |

操作（录屏的规则页）：旋转按钮；转动中再点一次（或空格）立即停止；按住空格连续旋转；+ / − 调投注；最大投注；自动旋转（选次数，停止按钮上显示剩余次数）；极速旋转（缩短转动时间）。

## 二、从录屏里看到的画面和节奏（`reference/jade-rabbit/frames/` 有对应截图）

- **竖屏布局**（录屏是 608×848 手机竖屏）：最上面是庙宇屋顶和站在屋顶上的吉祥物兔子；两侧红柱子挂"恭喜""发财"对联；卷轴两边竖排印着中奖线编号；卷轴下面一条信息栏，轮流显示"5 个奖金符号即可赢奖！""随机触发 8 次财富旋转！""赢取高达 5000 倍大奖！"，中奖时改为"赢得 X"。（01）
- **转动**：符号从上往下滚，三列从左到右依次停下；经常出现整列都是同一个符号的"叠放"（03）。
- **期待效果**：如果先停下的卷轴上奖金符号已经够多、还差最后一列就能凑够 5 个，最后一列外框发蓝光、转得更久才停。（04、13）
- **线奖展示**：中奖线画成一条发光的火焰线，两侧对应的线号亮起；中奖符号外面一圈光环并跳动，其他符号压暗；多条线时轮流展示。（02、12）
- **奖金符号**：金色牌匾上写着数值；凑够 5 个时，所有奖金符号一起发光，数值汇总到"赢得"栏。（06）
- **玉兔模式**：随机触发时吉祥物跳起来、游戏标志金光爆开（05）→ 红色卷轴"8 次财富旋转"配鞭炮烟花（07）→ 背景变红，卷轴上全是红色中国结空格，只落下金色奖金牌匾（08）→ 每次凑够 5 个就把牌匾数值加起来（09）→ 结束时大奖画面：吉祥物 + "大奖 / 巨奖 X"、金币雨（10）→ 回到主游戏显示"共赢得 X"（11）。
- **吉祥物**：平时在屋顶上待机，中奖、触发模式、大奖时有不同动作。
