## 转动不流畅的技术原因（审查员补充，留给 STEP-49）

- 滚动动画每 0.18 秒移动 28%，不是整数格，也不等于符号的重复周期，所以每圈都会跳一下。
- 还在转的列中途换图：结果一到，就用新盘面替换滚动条内容。
- 停轴没有减速和回弹。
- 玉兔模式里滚动的全是空格。

## 怎么验证

- 自动测试：`src/platform/mahjong-platform.test.ts` 新增 STEP-48 测试，覆盖以下几项：
  - 模式没打完时付费请求被拒绝；
  - 别人的父局号被拒绝；
  - 最后一次财富旋转之后的重试返回 409，且不扣款；
  - session 和回包都不带模式停点；
  - 玩家记录区分 8 个免费局；
  - 回放页显示整轮已转完。
- 浏览器复现：脚本在 scratchpad 的 harness/bugcheck.mjs、layoutcheck.mjs、platformcheck48.mjs。按审查员描述的方法逐条复现，修复后结果见 DEVLOG。
