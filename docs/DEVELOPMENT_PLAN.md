## 一、最终要做成什么

一个**自己的** 5 列 × 4 行、1024 Ways 老虎机网页游戏，只在本机运行、只用虚拟积分（没有充值、提现或真实货币）。

要求：

1. **规则是真的**：中奖完全由盘面和赔率表算出来，有单元测试保证，理论 RTP 可以精确计算。
2. **手感是好的**：点了马上转；滚轮有加速、匀速、减速、回弹的过程；逐列停下。
3. **界面是活的**：余额、投注、赢分、按钮都绑定真实状态，不再叠在一张截图上。
4. **代码好改**：逻辑、状态、画面分层，加功能时不需要对着像素调坐标。

## 二、架构（分三层）

```
src/engine/       纯逻辑：符号、卷轴条带、赔率表、1024 ways 计算、RTP 计算、回放  ← 不依赖 React/浏览器/Node
server.mjs        游戏服务器（供应商）：随机数 + 调用 engine + 每局永久记录      ← 不存余额，向平台钱包扣款/派彩
server/           游戏服务器的辅助模块：签名、局记录、回放页面
mock-operator.mjs 模拟平台（运营商）：玩家、余额、钱包接口、大厅页面            ← 只在本机，只有虚拟积分
src/game/     转动逻辑：滚轮运动、符号带、转动控制器                       ← 纯逻辑，可测试
src/ (UI)     React：每帧绘制滚轮 + 界面                                   ← 只负责"演出"结果
```

## 五、常用命令

```bash
npm install          # 安装依赖
npm start            # 同时启动模拟平台（http://127.0.0.1:8788）、游戏服务器（8787）和网页（4173），Ctrl+C 一起停
npm run operator     # 只启动模拟平台（默认 8788 端口）
npm run api          # 只启动游戏服务器（默认 8787 端口）
npm run check:provider  # 端到端检查（临时端口和临时数据，不影响你的存档）
npm run dev          # 只启动网页（默认 http://127.0.0.1:4173）
npm test             # 运行引擎单元测试
npm run rtp          # 打印精确 RTP + 100 万次模拟
npm run build        # 类型检查 + 打包
```

端口可以用环境变量改：`OPERATOR_PORT`、`API_PORT`、`WEB_PORT`。

**改了 `src/engine/` 或 `server.mjs` 之后必须重启 API（Ctrl+C 后重新 `npm start`）**（Node 只在启动时加载一次规则）。忘了重启时，网页会提示"旧版本"并禁止旋转。
